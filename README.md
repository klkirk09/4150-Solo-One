# multiple_screens_with_navigation

Kathleen Kirk's solo one assignemnt for CPSC 4150

# Description: 

This is a Flutter app that demonstrates my ability to build a multi-page Flutter application with navigation between pages.

# How to run:

Have Flutter installed, open the application inside Android Studio, and use the command ‘flutter run’. An Android emulator or a physical Android device will be needed. 

# Design Choices:

I kept everything simple and centered across both pages, adding padding between elements in each column to ensure they were spaced adequately apart. Each page has a light background color and a darker appBar at the top. I placed the page navigation buttons at the bottom of the screen to maintain a natural flow of eye movement across the page and to ease thumb access. The titles at the top are bolded, while the description text is lighter to avoid drawing the eye away.  I also used the network module to load images for a simpler application such as this one. All images and information on the application are supplied from Wikipedia.
